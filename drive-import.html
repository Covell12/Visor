Add files from Google Drive

Choose Google Docs and Slides files. Visor reads each one’s history, as the Visor button does on a Doc you have open, and adds it to your group project.

Project

Files

In Google Drive, select the files (hold Ctrl, or ⌘ on a Mac, to pick several) and press Ctrl+C or ⌘C, then paste them here. For one file, right-click it and choose Share → Copy link.

      Open in Chrome

        No Google Docs or Slides files are open in Chrome.

        Visor opens each file in a background tab, reads its history and closes it again. Only names, email addresses and counted figures go to the project, never the document’s text. You need edit access to a file to add it, the same rule Google Docs applies to version history.
